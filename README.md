# Aachman Studios Social Assets

Media library for creating Aachman Studios social content.

## Rules

- Assets in this repository may be used for Aachman Studios social posts.
- Prefer real project footage over AI-generated fake interfaces.
- Do not modify project logos.
- Do not invent features that aren't visible or documented.
- `gameplay/` contains real recordings.
- `screenshots/` contains real product screenshots.
- `bugs/` contains before/after development footage.
- `branding/` contains official logos and brand assets.
